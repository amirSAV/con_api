# CON API Agent

یک فریم‌ورک ایجنت خط فرمان (CLI) قدرتمند برای تعامل با مدل‌های زبانی بزرگ (LLM) از طریق API. این پروژه تاریخچه‌ی مکالمه، پرامپت سیستم و خروجی زنده‌ی فرآیند تفکر و پاسخ نهایی مدل را مدیریت می‌کند.

## ✨ ویژگی‌ها

- **یکپارچگی با API**: ارتباط روان با مدل‌های سازگار با OpenAI.
- **نمایش زنده‌ی استریم**: نمایش لحظه‌ای وضعیت مدل، فرآیند تفکر و پاسخ تولیدشده با استفاده از کتابخانه‌ی `rich` برای ظاهری بهتر در ترمینال.
- **مدیریت وضعیت**: پیگیری وضعیت ایجنت (در حال اتصال، در حال تفکر، در حال نوشتن، تمام‌شده) و مصرف توکن در طول نشست.
- **ذخیره‌ی تاریخچه**: ذخیره و بارگذاری خودکار تاریخچه‌ی مکالمه.
- **ورودی منعطف**: پشتیبانی از تعریف پرامپت و پیام سیستم به‌صورت درون‌خطی و از طریق فایل‌های کانفیگ خارجی.
- **معیارهای دقیق**: ارائه‌ی خلاصه‌ای مختصر پس از اتمام، شامل زمان سپری‌شده، توکن‌های پرامپت، توکن‌های تکمیل و کل توکن‌ها.
- **مکانیزم تفکر**: پشتیبانی از بلوک‌های استدلال/تفکر صریح که می‌توانند از پاسخ نهایی جدا شوند تا خروجی واضح‌تر باشد.

## 📋 پیش‌نیازها

- پایتون ۳.۱۰ یا بالاتر
- `pip` (نصب‌کننده‌ی پکیج پایتون)

## 🚀 نصب

۱. **کلون کردن مخزن**
   ```bash
   git clone https://github.com/amirSAV/con_api.git
   cd con_api
   ```

۲. **راه‌اندازی محیط مجازی** (توصیه‌شده)
   ```bash
   python -m venv venv
   source venv/bin/activate  # در ویندوز: venv\Scripts\activate
   ```

۳. **نصب وابستگی‌ها**
   ```bash
   pip install -r requirements.txt
   ```

## ⚙️ تنظیمات

یک فایل `config.json` در ریشه‌ی پروژه بسازید. می‌توانید نمونه‌ی زیر را کپی کرده و مقادیر را تنظیم کنید.

### نمونه‌ی `config.json`

```json
{
  "api_url": "https://api.openai.com/v1/chat/completions",
  "api_key": "sk-your-api-key-here",
  "model": "gpt-4o-mini",
  "system_prompt": "You are a helpful assistant.",
  "system_prompt_file": "",
  "prompt": "Hello!",
  "prompt_file": "",
  "enable_thinking": false,
  "history_file": "history.json",
  "output_file": "output.txt",
  "live_display": true,
  "stream": true,
  "temperature": 0.7,
  "max_tokens": 0,
  "timeout": 60
}
```

### فیلدهای کانفیگ

| فیلد                  | توضیح                                                                                             | پیش‌فرض        |
|-----------------------|---------------------------------------------------------------------------------------------------|----------------|
| `api_url`              | آدرس کامل endpoint چت (مثلاً `https://api.openai.com/v1/chat/completions`).                        | —              |
| `api_key`              | کلید مخفی API شما.                                                                                 | —              |
| `model`                | نام مدلی که استفاده می‌شود (مثلاً `gpt-4o-mini`، `deepseek-chat`).                                 | —              |
| `system_prompt`        | پرامپت سیستم به‌صورت درون‌خطی. اگر خالی باشد، از `system_prompt_file` استفاده می‌شود.              | `""`           |
| `system_prompt_file`   | مسیر فایلی که پرامپت سیستم را در خود دارد. اگر `system_prompt` مقدار داشته باشد، نادیده گرفته می‌شود. | `""`           |
| `prompt`               | پرامپت کاربر به‌صورت درون‌خطی. اگر خالی باشد، از `prompt_file` استفاده می‌شود.                      | `""`           |
| `prompt_file`          | مسیر فایلی که پرامپت کاربر را در خود دارد. اگر `prompt` مقدار داشته باشد، نادیده گرفته می‌شود.      | `""`           |
| `enable_thinking`      | فعال‌سازی بلوک‌های تفکر/استدلال صریح (فقط برای مدل‌هایی که پشتیبانی می‌کنند، مثل DeepSeek-R1).       | `false`        |
| `history_file`         | مسیر فایلی که تاریخچه‌ی مکالمه در آن ذخیره می‌شود.                                                  | `history.json` |
| `output_file`          | مسیر فایلی که **فقط پاسخ نهایی مدل** در آن ذخیره می‌شود، بدون هیچ متن اضافی، متادیتا یا قالب‌بندی.   | `output.txt`   |
| `live_display`         | نمایش خروجی استریم به‌صورت زنده در ترمینال.                                                         | `true`         |
| `stream`               | استفاده از پاسخ‌های استریم API.                                                                    | `true`         |
| `temperature`          | دمای نمونه‌گیری (۰.۰ تا ۲.۰).                                                                      | `0.7`          |
| `max_tokens`           | حداکثر تعداد توکن تولیدی. **مقدار `0` یعنی بدون محدودیت.**                                          | `0`            |
| `timeout`              | مهلت درخواست به **ثانیه**.                                                                          | `60`           |

> **توجه:** `api_url` باید به endpoint کامل (شامل `/v1/chat/completions`) اشاره کند. برای سرویس‌دهنده‌های سازگار با OpenAI، این معمولاً به شکل `<base_url>/v1/chat/completions` است.

## 🕹️ استفاده

پس از تنظیم `config.json`، ایجنت را اجرا کنید:

```bash
python main.py
```

ایجنت به API متصل می‌شود، خروجی استریم را به‌صورت زنده نمایش می‌دهد و تاریخچه‌ی مکالمه و خروجی نهایی را در فایل‌های مشخص‌شده ذخیره می‌کند.

> **نکته:** فایل `output_file` **فقط شامل پاسخ نهایی مدل** است — بدون مهر زمانی، بدون خطوط وضعیت، بدون معیارها و بدون بلوک‌های تفکر/استدلال. هر چیز دیگری (تغییرات وضعیت، تفکر، شمارش توکن، زمان سپری‌شده) فقط در ترمینال از طریق نمایش زنده نشان داده می‌شود.
